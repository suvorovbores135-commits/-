# my-site

A simple static personal website: plain HTML and CSS, no build step.

## Files

- `index.html`: the page content (header, about, projects, contact, footer).
- `style.css`: styles, with light and dark color themes via `prefers-color-scheme`.

## Preview locally

Open `index.html` in a browser, or run a small local server:

```sh
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Customize

Replace the placeholder name, text, and project entries in `index.html`, and adjust the colors at the top of `style.css`.
